# rodokmen-data is a one-way Export, not the source of truth

The database is the source of truth for the Tree. Every night the server writes a one-way Export to a private repo (`rodokmen-export`, see ADR 0010; first planned as rodokmen-data): one Markdown note per record plus a GEDCOM file, with Living people reduced as in any Export. Nobody edits that repo by hand; Agents may read it, but their changes still arrive as Proposals. Page images stay out of Git and live in object storage and its Backups. This reverses the draft spec, where a Markdown vault in Git was the source of truth: with many contributors, review and history belong in the database.
