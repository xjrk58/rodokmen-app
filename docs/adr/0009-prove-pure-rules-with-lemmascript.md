# Prove pure rules with LemmaScript

Rules of the Tree that are pure logic, such as the Living rule and the ranges of EDTF dates, are proved as well as tested. Each rule lives in a pure TypeScript function whose `//@` lines state the requirement's scenarios as properties. LemmaScript turns the function into Dafny, and CI fails unless Dafny proves it (`lsc check`). The function names the requirement it proves with `//@ contract <capability>: <Requirement>`, and docs/verification.md traces every proof to OpenSpec; a name that matches no requirement fails CI. Code that LemmaScript cannot model (regular expressions, `Date`, I/O, `await`) stays in a thin unverified shell that calls the pure function and is covered by tests. LemmaScript is a tech preview with known translation bugs, so a proof also trusts its translation, Dafny with Z3, and a model where numbers are integers. LemmaScript and Dafny are pinned, the generated Dafny is committed and read in review, and everything a proof assumes rather than proves (requires met by the shell, `//@ assume`, `extern`, hand-written axioms) is listed in docs/verification.md and kept to a minimum.
