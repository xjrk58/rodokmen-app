# Contributions go through reviewed Proposals

Several relatives, most of them non-technical, and AI agents will add to one shared Tree. Every change from a Member or an Agent therefore arrives as a Proposal, and an Editor must accept it before other Members see it. Only Editors change the Tree directly, and every change records who made it, when, and which Citation supports it. We chose review over open editing to keep mistakes and duplicate people out of the Tree, and accept that publishing is slower. Agents get no direct write access at all.
