# Store private copies of cited register pages

Each Citation carries an image of the register page it points to. The image is stored with the Tree and visible only to Members, instead of the Citation holding only a link to the archive's online viewer. Archive portals change their URLs and viewers, and a Citation has to stay checkable for as long as the Tree exists. The copies serve the family's private research and are never published. The one exception is scan reading, which may send a page to Anthropic's API to be read, only while the Owner allows it (ADR 0011). This replaces the earlier draft rule "link only, no scans".

## Considered Options

- **Link only**: rejected, because archive links rot and the evidence disappears with them.
- **Public copies**: rejected, because archives allow copies for personal research but not republication.
