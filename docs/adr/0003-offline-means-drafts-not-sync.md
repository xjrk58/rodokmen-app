# Offline means Drafts, not sync

Members can write Drafts without network, for example in an archive reading room, and submit them as Proposals once they are back online. The server never merges offline edits. Each Proposal records the version of the records it was based on, and the Editor resolves any conflict during review. Full offline sync was rejected: it would be the most expensive part of the system to build, and review already gives conflicts a human owner.
